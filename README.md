# AI Chatbot Starter

A simple, self-contained starter kit for building **basic JuicyChat character cards**.

This repo is meant to be loaded by an AI assistant. It is not a full production bible. It is enough to get a usable bot out the door.

## Load this first

1. [`PLAYBOOK.md`](PLAYBOOK.md) — short workflow
2. [`skills/juicychat-bot-creator/SKILL.md`](skills/juicychat-bot-creator/SKILL.md) — card writer
3. [`skills/juicychat-bot-creator/references/styleguide.md`](skills/juicychat-bot-creator/references/styleguide.md) — naming and format
4. Optional: [`skills/juicychat-brainstorm/SKILL.md`](skills/juicychat-brainstorm/SKILL.md) — if the idea is still vague
5. Optional: [`skills/anime-oc-looks/SKILL.md`](skills/anime-oc-looks/SKILL.md) — if you need a face
6. Optional: [`skills/juicychat-figure-generator/SKILL.md`](skills/juicychat-figure-generator/SKILL.md) — if you need a JuicyChat Figure prompt

## What you get

| Path | Job |
|---|---|
| `PLAYBOOK.md` | Concept → cards → done |
| `skills/juicychat-bot-creator/` | Title, Bio, Situation, World, Opening, Reply Style |
| `skills/juicychat-brainstorm/` | Three premise options, pick one |
| `skills/anime-oc-looks/` | Two or three looks, pick one |
| `skills/juicychat-figure-generator/` | Short tagged Figure / PFP prompt |
| `examples/` | One generic sample package |

## What you do not get

- No character catalog
- No archive of shipped bots
- No persona library
- No advanced engines, trackers, or scoring systems
- No illustration quality lab

If you need those, this is the wrong repo.

## Output

A finished bot is **five markdown boxes**:

1. Title + Bio
2. Situation
3. World
4. Opening
5. Reply Style (short sample replies)

Copy them into JuicyChat. That is the whole job.
