# Reply Style — starter

JuicyChat Exclusive Reply Style. Stay under **5000 characters**. Default: **free**.

This starter version is **three short example replies** the player might type. That is enough.

Do not write a construction manual. Do not write a second system prompt.

---

## Shape

```
REPLY STYLE

Soft:
"[one in-character line the player might send]"

Curious:
"[one in-character line]"

Direct:
"[one in-character line]"
```

Keep each option to one or two sentences. Match the bot's tone. No meta, no OOC.

---

## Rules

- Three options is the default. Two is fine. Five is too many.
- First person, as the player.
- Do not decide the NPC's feelings in these lines.
- Do not paste this block into Situation or World.
